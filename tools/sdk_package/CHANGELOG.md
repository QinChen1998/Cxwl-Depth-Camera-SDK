# Windows x64 SDK 3.1.0

- 相机使用预装的固定地址镜像，经物理 USB 网卡上的 CX2 TCP 连接。SDK 首次接入时生成本机登记密钥，同序号相机全擦后可通过首次接入更新档案。
- 收到迟到的深度帧后，SDK 请求板端最新深度，保持原有帧龄限制、同帧 XYZ 与六档语义。Windows 连接会等待所选 USB 网卡的地址就绪。
- 保留 ABI v3 和 46 个公开 C 函数。旧证书版固件使用与其配套的 SDK。

## 3.0.0

ABI v3 提供 46 个公开 C 函数。六种模式通过预装的设备服务采集。点云使用板端同帧 XYZ，RGB 校正使用独立工具。客户端须按 ABI v3 重新编译。
